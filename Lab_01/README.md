# Online Store Inventory Manager

Навчальний проєкт з дисципліни «Професійний Python» (Лабораторна робота №1, Варіант 3).

## Опис проєкту
Консольний застосунок для інвентаризації та аналітики товарних залишків інтернет-магазину. Підтримує обчислення балансової вартості, фільтрацію за категоріями, пошук товарів та додавання нових записів із валідацією.

## Вимоги
* Python 3.11+
* Git
